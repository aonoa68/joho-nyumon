# 【第13回 余談】文章もデータになる ― テキストマイニングと生成AI

> 第13回では「数値」のデータを分析してレポートを書きました。
> でも、分析できるのは数字だけではありません。**アンケートの自由記述や、演説・SNSの「文章」も、データとして分析できます。** これを **テキストマイニング** と呼びます。

## なぜ今日これを紹介するのか

```text
数値の分析（第13回まで）
↓
文章の分析（テキストマイニング）＝ データの世界はもっと広い
```

「データ＝数字」だと思いがちですが、**世の中の情報の多くは"文章"**です。
その文章も、AIを使えば「見える化」できる——**分析できる対象は、思っているよりずっと広い**。
これから先、みなさんが出会うデータの多くは、きっと文章の形をしています。
